# Как запустить твой сайт — просто, по шагам (для ноутбука с Windows)

Не переживай, если ты никогда этого не делала. Здесь объяснено каждое слово. Все шаги — с ноутбука, мышкой и клавиатурой, телефон не понадобится.

Что нам вообще нужно сделать (3 предложения):
1. Получить бесплатный "пропуск" для использования ИИ (это просто длинный код-ключ).
2. Загрузить файлы твоего сайта на GitHub — это как облачное хранилище для кода (как Google Диск, но для программистов).
3. Подключить это к Vercel — сервису, который берёт код с GitHub и превращает его в настоящий работающий сайт со своей ссылкой.

Дальше — подробно.

---

## Шаг 1. Получить ключ ИИ (Groq)

1. Открой браузер (Chrome, Edge — любой) и перейди на **console.groq.com**
2. Нажми кнопку входа/регистрации (Sign in / Sign up). Проще всего — через кнопку "Continue with Google", если у тебя есть Google-почта.
3. Когда войдёшь — слева будет меню. Найди пункт **API Keys**.
4. Нажми кнопку **Create API Key**.
5. Впиши любое название (например "lesson-app") и подтверди.
6. Появится длинная строка кода, начинается с `gsk_...` — это и есть твой ключ.
7. **Сразу скопируй его** (иконка копирования рядом со строкой) и вставь куда-нибудь, где не потеряется — например, в Блокнот на рабочем столе. Второй раз тебе его не покажут.

✅ Готово — у тебя есть ключ. Он понадобится на Шаге 3.

---

## Шаг 2. Загрузить файлы на GitHub

**Что такое GitHub:** сайт, где хранится код. Нам нужно просто один раз туда всё закинуть.

1. Скачай файл **lesson-app.zip**, который я прикрепила в чате — обычно он попадает в папку **Загрузки** (Downloads) на твоём ноутбуке.
2. Открой папку **Загрузки** через Проводник (иконка папки на панели задач внизу экрана).
3. Найди файл `lesson-app.zip`, нажми на него **правой кнопкой мыши** → в меню выбери **Извлечь всё...** (Extract All...) → в появившемся окне нажми **Извлечь** (Extract).
4. Появится новая папка `lesson-app` с файлами внутри: `index.html`, `package.json`, `README.md` и папка `api`. Оставь это окно открытым.
5. Открой **github.com** в браузере.
6. Нажми **Sign up** (регистрация), если аккаунта ещё нет — понадобится только почта и пароль.
7. После входа нажми зелёную кнопку **New** (или **New repository**), обычно она в верхней части главной страницы.
8. В поле "Repository name" впиши: `lesson-generator`
9. Ничего больше не трогай, пролистай вниз и нажми зелёную кнопку **Create repository**.
10. На новой странице найди ссылку **uploading an existing file** (по центру экрана, синим текстом) и нажми на неё.
11. Вернись к папке `lesson-app`, которую распаковала на шаге 3-4. Выдели там всё содержимое (нажми на любой файл внутри папки и сразу **Ctrl+A**).
12. **Не отпуская мышку после клика**, перетащи выделенное прямо в окно браузера — на область с надписью "Drag files here to add them to your repository".
13. Подожди, пока файлы загрузятся (появятся полоски/список файлов), пролистай страницу вниз и нажми зелёную кнопку **Commit changes**.

✅ Готово — код лежит на GitHub.

---

## Шаг 3. Превратить код в работающий сайт (Vercel)

**Что такое Vercel:** сервис, который бесплатно "включает" твой код как настоящий сайт в интернете со своей ссылкой.

1. Открой **vercel.com**
2. Нажми **Sign Up**, выбери **Continue with GitHub** — аккаунты свяжутся автоматически.
3. После входа нажми **Add New...** → **Project**.
4. В списке появится твой репозиторий `lesson-generator` — нажми рядом с ним кнопку **Import**.
5. Откроется страница настроек. **Не нажимай Deploy сразу.** Найди раздел **Environment Variables** и разверни его (нажми на название раздела).
6. В нём два поля:
   - В поле **Name** впиши: `GROQ_API_KEY`
   - В поле **Value** вставь ключ из Блокнота (тот, что начинается с `gsk_`)
7. Нажми кнопку **Add**, чтобы переменная добавилась.
8. Теперь нажми большую кнопку **Deploy**.
9. Подожди примерно минуту — увидишь анимацию и надпись вроде "Congratulations!".
10. Появится ссылка вида `lesson-generator-xxxx.vercel.app` — **это и есть твой готовый сайт**.

✅ Всё. Ссылку можно открывать в браузере и отправлять кому угодно.
